# Calculator App

Simple calculator built with **Vanilla JavaScript (DOM + Logic)**.
Project ini fokus ke fundamental frontend: event handling, state management sederhana, dan manipulasi DOM.

---

## ✨ Features

* Basic operations: `+ - * /`
* Clear & delete input
* Responsive button layout
* Event delegation (efficient DOM handling)

---

## 🛠 Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla)

---

## 📂 Project Structure

```
calculator-app/
├── index.html
├── style.css
└── script.js
```

---

## 🚀 Getting Started

1. Clone repository:

```bash
git clone https://github.com/nindyoo/calculator-app.git
```

2. Masuk ke folder:

```bash
cd calculator-app
```

3. Buka `index.html` di browser

---

## 🧠 Learning Goals

Project ini dibuat untuk latihan:

* DOM manipulation
* Event delegation
* Basic state handling
* Simple expression evaluation

---

## ⚠️ Notes

Project ini menggunakan `eval()` untuk kalkulasi agar tetap sederhana.
Di production app, sebaiknya gunakan custom parser untuk keamanan dan kontrol yang lebih baik.
